Project Homeland

Homeland é uma galeria de arte e histórias que conecta pessoas de diversas partes do mundo através de suas cidades natais. A página apresenta fotos de cidades ao redor do mundo, acompanhadas de informações sobre sua história, cultura e curiosidades, além do nome dos autores responsáveis por compartilhar cada história.

## Funcionalidade

O objetivo do projeto é aproximar pessoas de diferentes origens, permitindo que conheçam um pouco mais sobre a cidade natal de cada colaborador através de fotos e relatos pessoais.

## Tecnologias e boas práticas utilizadas

- **Metodologia BEM** — organização e nomenclatura das classes CSS, facilitando a manutenção e escalabilidade do código.
- **Acessibilidade** — estrutura pensada para pessoas com deficiência, com uso de atributos como `alt` descritivo nas imagens e organização semântica do conteúdo.
- **HTML semântico** — uso de tags como `<header>`, `<main>`, `<section>` e `<footer>` para melhorar a organização, o SEO e a leitura por tecnologias assistivas.
- **Responsividade** — layout adaptado para diferentes tamanhos de tela, incluindo smartphones.
